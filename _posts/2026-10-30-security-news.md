## ニュース本文

### 1. Binance で最大約58億ドル規模の流出の可能性（調査中）

**何が起きたか**
Binance は、最大約58億ドル相当の暗号資産に関わる可能性のあるセキュリティ上の問題を調査中だと報じられています（10月29日）。確認されれば過去最大の暗号資産ハッキングになり得ます。

**影響範囲**
ブロックチェーン分析会社 Arkham が「binance-hacker」とラベルした55アドレスに約57.8億ドル相当が保有されていると報じられていますが、これはウォレット内の評価額であり、盗まれた確定額ではありません。ホットウォレットからの移転額は約25億ドル超、追加分を含め約35億ドルとの個人の分析も出ています。不正な移転だったか、侵入経路、被害総額、攻撃者の特定はいずれも**未確認**です。

**現状と対応**
Binance は「ユーザーの資産は完全に安全」と説明し、詐欺や非公式リンクへの注意を呼びかけています。Tether は約15.7億ドル超の USDT を、Circle は約8億ドル超の USDC を凍結したと報じられています。続報待ちの状況です。

**やさしい解説**
銀行の大きな金庫室から巨額の現金が動いた形跡があるものの、盗難なのか、内部の資金移動なのかを銀行が確認している段階、というイメージです。利用者は、取引所からの連絡をうたうメールやSNSの投稿、DMのリンクを開かず、公式アプリ・公式サイトの案内だけを確認してください。

### 2. 日本航空（JAL）の旅客情報が Amadeus への不正アクセスで流出

**何が起きたか**
航空会社の予約・発券・搭乗手続きに使われる旅客サービスシステムを提供する Amadeus への不正アクセスにより、JAL の旅客情報が流出したと報じられています。JAL によれば、Amadeus から10月23日に通知があり、不正アクセスは2023年8月から2026年9月までの期間に及んだとされます。

**影響範囲**
約9.2万人。うち約9万人は予約番号、氏名、搭乗日、区間、搭乗クラス。約2,000人はそれに加えてメールアドレス、電話番号、パスポート番号、国籍、マイレージ番号、航空券番号、座席番号などが対象です。クレジットカード番号とパスワードは含まれないと JAL は説明しています。全日空（ANA）、アシアナ航空、大韓航空も同じ脆弱性の影響を確認したと報じられています。

**現状と対応**
JAL は現時点で情報の悪用は確認しておらず、運航への影響もないとしています。Amadeus が必要な対策を実施済みとされますが、全体の影響範囲（他の航空会社・国）は Amadeus から詳細が示されておらず**未確認**です。

**やさしい解説**
航空会社が使っている「共通の予約台帳」の管理会社に泥棒が入ったようなものです。予約情報を知っている相手からの「便の変更」「搭乗手続き」を装う偽メール・偽SMSに注意してください。旅行関連の連絡はメールのリンクからではなく、航空会社の公式アプリやサイトから確認するのが安全です。

### 3. Cisco ASA/FTD の VPN の脆弱性 CVE-2026-76418、悪用確認（ファイアウォールが再起動）

**何が起きたか**
Cisco Secure Firewall の ASA ソフトウェアと FTD ソフトウェアのリモートアクセス SSL VPN にある脆弱性 CVE-2026-76418（CVSS 8.6）が、実際に悪用されていると Cisco が公表しました。認証なしの細工したリクエストでデバイスを再起動させ、サービス停止（DoS）に至らせます。

**影響範囲**
対象は、脆弱なバージョンで SSL VPN のログイン機能が外部から到達可能、かつトンネルグループに二要素目の認証（セカンダリ認証）を設定している構成です。悪用の開始時期、攻撃者、規模は Cisco から示されていません。

**現状と対応**
修正版が公開されています（例：ASA 9.20 系は 9.20.4.50、9.22 系は 9.22.3.200、FTD 7.4 系は 7.4.9、7.6 系は 7.6.7 など。系統別の詳細は Cisco の公報を参照）。暫定策として、DefaultWEBVPNGroup がセカンダリ認証を使っていなければトンネルグループ一覧を無効化する、または該当グループのセカンダリ認証を無効化する方法が案内されています。CISA の KEV 追加状況は本稿作成時点で未確認です。

**やさしい解説**
会社の出入口（VPN の受付）に、特定の手順で呼びかけると受付が固まって再起動してしまう不具合があり、すでに悪用されている状況です。直接データが盗まれる話ではなく、リモートワークなどの接続が止まるのが主な影響です。利用者側の対応は不要で、機器の管理者が更新を確認します。

**ソース**
- [Cisco Patches Actively Exploited ASA and FTD VPN Flaw That Can Crash Firewalls（The Hacker News・Cisco 公報の内容を報道。公報本体は未確認）](https://thehackernews.com/2026/10/cisco-patches-actively-exploited-asa.html)
- [New Cisco firewall zero-day exploited to crash SSL VPN devices（BleepingComputer）](https://www.bleepingcomputer.com/news/security/cisco-warns-of-firewall-zero-day-exploited-to-crash-ssl-vpn-devices/)

### 4. Linux カーネルの TCP の脆弱性 CVE-2026-98432（修正未提供のディストリビューションあり）

**何が起きたか**
Linux カーネルの IPv4 の TCP 接続確立処理に、競合状態から「解放後メモリの使用（use-after-free）」を引き起こす脆弱性 CVE-2026-98432 があると報じられています。Linux 4.4 から存在し、カーネル開発側の評価は9.8（Red Hat・Oracle・SUSE は8.1、Amazon は7.0と評価が分かれています）。

**影響範囲**
Anthropic は10月27日、Claude が MPTCP（マルチパスTCP）のリスナーを持つサーバーに対する root 権限取得のエクスプロイトを作成できたと発表したとされます（コードは非公開）。10月29日時点で、実際の攻撃は報告されておらず、CISA の KEV にも未掲載です。

**現状と対応**
上流カーネルは 5.10.272、6.1.190、6.6.159、6.12.113、6.18.56 などで修正済み。Debian と Oracle Linux は修正版を提供済みですが、Ubuntu（22.04/24.04/26.04 など）は作業中で修正未提供、RHEL 8/9/10 は修正時期未定と報じられています（RHEL 7 は対象外）。Red Hat は採用基準を満たす緩和策はないとしています。

**やさしい解説**
建物の設計図の初期から潜んでいた「ドアの閉まるタイミング次第で鍵が効かなくなる」欠陥です。すでに攻撃が広がっている段階ではありませんが、実証されたため狙われやすくなります。サーバーの管理者は、利用中のディストリビューションの修正状況を確認し、提供され次第更新・再起動してください。

**ソース**
- [Linux Kernel TCP Flaw With 9.8 CVSS Score Affects Ubuntu, Red Hat and Other Distributions（The Hacker News・報道。ベンダー公報・CVE レコードは未確認）](https://thehackernews.com/2026/10/linux-kernel-tcp-flaw-with-98-cvss.html)

### 5. Polymarket、第三者サービス（DebugBear）経由のスクリプト改ざんで約250万ドルが流出

**何が起きたか**
予測市場 Polymarket が、利用していた第三者サービスの侵害により、暗号資産を抜き取る JavaScript を利用者に配信されてしまい、約250万ドルが攻撃者側のウォレットに移されたと報じられています（10月29日）。

**影響範囲**
報道によれば、サイト性能監視サービス DebugBear の基盤にある不正スクリプトが、ログイン中の利用者のセッションを使って取引ポジションの清算やトークン移転を行いました。影響を受けた利用者数と被害総額は Polymarket から開示されていません。

**現状と対応**
Polymarket は取引を一時停止後、DebugBear の連携を本番から外して再開し、被害者に全額補償すると表明、法執行機関にも報告したとされます。DebugBear は調査中で、顧客に自社の計測コードを外すよう案内したと報じられています。

**やさしい解説**
自社サイトは無事でも、サイトに組み込んだ「外部の部品」が乗っ取られると、利用者のブラウザ上で悪さをされます（10月29日に掲載した Convertr の件と同じ型です）。Polymarket を使っている方は、取引履歴や承認（アプローバル）設定を確認し、補償の案内は公式発表だけを信用してください。

**ソース**

### 6. 【続報】お名前.com デスクトップクラウド：公開された情報の顧客に見舞金、報奨金制度も開始

**何が起きたか**
GMOインターネットは第12報として、攻撃者に情報を公開された顧客への見舞金の支払いを公表しました（10月27日付）。続いて10月28日12時から、サイバー犯罪撲滅を目的とした報奨金制度（総額上限100万米ドル）の情報提供の受付を開始したとされます。

**影響範囲**
公開された情報の区分ごとに、氏名・連絡先など基本情報は1万円、取引口座のIDやパスワードなど金融・認証情報は1.5万円、センシティブな情報は2.5万円で、複数区分は合算（1公開あたり上限300万円）とされています。支払いは、公開情報に当該顧客のデータが含まれることを確認できた場合に限られます。

**現状と対応**
GMO は攻撃者の要求には応じないとしています。不審な連絡や詐欺の被害を受けた顧客向けに、24時間対応の相談窓口も設けられています。金額は公開範囲・方法の変化により見直される場合があります。

**やさしい解説**
「情報が公開された人にお金を払う」という救済策です。対象かどうかは自分では判断しにくいため、GMO からの個別連絡や公式ページの案内を確認してください。見舞金をうたう偽メールが出回る可能性もあるので、メールのリンクは開かず、公式ページから手続きしましょう。

**ソース**
- [GMOインターネットグループ お知らせ（一次）](https://group.gmo/info/alert/2026102705/)
- [ScanNetSecurity（報道）](https://scan.netsecurity.ne.jp/article/2026/10/30/56632.html)

### 7. 【続報】PHP2Shell と Linux カーネルの脆弱性（Fragnesia）の連鎖攻撃、実被害の報告

**何が起きたか**
10月29日付の報道で、Linux カーネルの脆弱性 CVE-2026-46300（通称 Fragnesia）が PHP2Shell の2件（CVE-2026-109618、CVE-2026-109619）と連鎖して悪用されていると CISA が警告したと報じられました（KEV 追加自体は前回掲載済み）。

**影響範囲**
新しい事実として、セキュリティ企業 Dream Security の報告では、米国・日本・台湾・韓国の25台のサーバーで root 権限が奪われ、さらに米国政府関連の環境の3台が狙われたとされます。別の研究者は、PHP 8.4.26 の Apache（mod_php）環境への実際の PHP2Shell 攻撃を報告しています。公開された概念実証コードがあるとされます。

**現状と対応**
PHP とカーネルの両方の更新が必要です。報道では、KEV の期限は10月31日とされていた件を含め、期限の詳細は記事上で明確でない部分があり、確認できていません。

**やさしい解説**
前回お伝えした「玄関の鍵」と「万能の合鍵」の組み合わせが、実際に世界中のサーバーで使われた、という続報です。自分でサーバーを運用していない方の対応は不要。運用している方は、PHP と OS カーネルの更新を急いでください。

**ソース**
- [CISA warns of Fragnesia Linux flaw chained in PHP2Shell attacks（BleepingComputer・報道）](https://www.bleepingcomputer.com/news/security/cisa-warns-of-fragnesia-linux-flaw-chained-in-php2shell-attacks/)

### 8. 【続報】Cisco SD-WAN の脆弱性 CVE-2026-20127 を悪用する新たなマルウェア「KeyDrift」

**何が起きたか**
Volt Typhoon の「Silent Train」の件（10月29日掲載）で触れた Cisco Catalyst SD-WAN の認証バイパスの脆弱性 CVE-2026-20127 について、Cisco Talos が、新たに確認された攻撃グループ UAT-11473 による悪用と、独自マルウェア「KeyDrift」の存在を報告したと報じられています。

**影響範囲**
対象は Cisco Catalyst SD-WAN Controller と Manager で、宇宙・衛星、防衛・航空宇宙、政策研究機関が標的とされています。KeyDrift は、コントローラー上で長期的に居座り、制御通信から暗号鍵の素材を抜き取るよう作られているとされます。Talos は Volt Typhoon の基盤との重なりがあるとしつつ、断定はしていないと報じられています。

**現状と対応**
この脆弱性は2026年2月に Cisco が修正済みです。未適用の組織は更新し、Cisco のハードニングガイドに従ってください。

**やさしい解説**
前回の「泥棒が他人の家を経由する」話の続きで、その中継役の家の鍵（管理装置）が盗まれ続けた、という内容です。一般の方の対応は不要です。SD-WAN を使う組織は、更新と管理画面の公開状況の確認が必要です。

**ソース**
- [Hackers exploit Cisco SD-WAN flaw to deploy custom KeyDrift malware（BleepingComputer・Cisco Talos の報告を報道）](https://www.bleepingcomputer.com/news/security/hackers-exploit-cisco-sd-wan-flaw-to-deploy-custom-keydrift-malware/)

## 今日やること

**一般利用者向け**
- Binance や Polymarket などの暗号資産サービスを使っている方は、公式発表以外のメール・SNS・DMのリンクを開かない。取引履歴と承認設定を確認する。
- JAL・ANA などの予約があり、予約情報の悪用が心配な方は、旅行関連の連絡を公式アプリ・サイトから確認する。
- お名前.com デスクトップクラウドの利用者は、GMO の公式案内を確認する。見舞金をうたう不審なメールに注意する。

**IT担当者向け**
- Cisco ASA/FTD（CVE-2026-76418）、SD-WAN（CVE-2026-20127）の更新状況と、VPN／管理画面の外部公開を確認する。
- Linux カーネル（CVE-2026-98432、CVE-2026-46300）と PHP（CVE-2026-109618／109619）の更新を確認する。Ubuntu・RHEL は修正版の提供状況を随時確認する。
- サイトに外部スクリプト（性能監視・解析など）を組み込んでいる場合は、必要性と提供元の信頼性を点検する。
