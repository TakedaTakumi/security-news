## 1. 【続報】Cursor が侵害の原因を公表：Fireworks AI 経由で流出した鍵が発端

**何が起きたか**
10月末に掲載した、Cursor のマーケットプレイスに偽の Claude Code 拡張機能が置かれた件の続報です。Cursor は11月13日付の更新で、取引先の Fireworks AI が誤って露出させたアクセスキーを攻撃者が使い、過去のコーディングエージェントの履歴を保存した読み取り専用の保管領域からデータを複製した、と説明しました。履歴の一部には伏せられていない API 認証情報が含まれており、それを足がかりに社内の SaaS ツールにも入られたとのことです。

**影響範囲**
- 履歴が流出したのは、プライバシーモードを使っていないユーザーの2025年中心のデータで、ユーザー全体の0.05%未満とされます。API 認証情報が漏れた顧客は0.01%未満です。
- ほかに、過去のテスト用ソースコード、サポート関連の情報、製品の利用指標、一部のエージェント会話の要約、サポートに送られた認証情報が取得されたとされます。
- 10月29日に置かれた悪意ある版は 2.1.312 と 2.1.313 で、約11時間公開されました。入手した可能性があるのは最大5,000人です。コーディングの不具合により、多くの環境ではバックドアが入らなかった可能性が高いと報じられています。
- 本番環境、公式アプリの更新、顧客のコードリポジトリ、プライバシーモード利用者のコードとプロンプトは影響を受けていないと、Cursor は述べています（同社の主張）。

**現状と対応**
Cursor は漏れた鍵の無効化、認証情報の更新、推論通信の Fireworks からの切り離し、マーケットプレイスの再構築を行ったとしています。該当版を入れた方は、Cursor の案内に従った対処が必要で、拡張機能を削除するだけでは不十分な場合があるとされています。影響を受ける可能性のある管理者や顧客には、同社から個別に連絡が行われています。連絡が来なかった方は、流出した履歴に含まれていなかったと同社は説明しています。

**やさしい解説**
取引先に貸した合鍵が外で落とされ、それを拾った人が倉庫に入り、中にあった別の鍵（認証情報）でさらに奥の部屋まで開けた、という流れです。開発ツールを使う方は、2.1.312 または 2.1.313 を入れた覚えがあれば、Cursor の公式案内を見て、パスワードや API キーの更新と SSH 設定の確認を行ってください。心当たりがなければ、特別な操作は不要です。

## 2. 米当局が北朝鮮系「FaceStealer」キャンペーンのインフラを押収

**何が起きたか**
BleepingComputer（11月14日）によると、米政府は、北朝鮮系とされる詐欺的な接触型キャンペーン「FaceStealer」のクラウド上のインフラを押収しました。Arctic Wolf は、この活動を BlueNoroff に結びつけています。報道では、約18カ月続き、暗号資産の被害は4億ドル超とされています。

**影響範囲**
Arctic Wolf は、58カ国で677人の標的を確認したとされます。創業者や幹部が中心で、米当局は、技術系の従業員を密かに撮影した900本超のウェブカメラ動画を確認したと報じられています。手口は、乗っ取った Telegram・LinkedIn・Slack・Discord のアカウントからビデオ会議に誘い、技術的な不具合を装って偽の「修正」を実行させるものです。マルウェアは暗号資産や会議アプリの認証情報、連絡先、カメラ映像などを盗むとされます。FBI は、侵入から数カ月〜1年以上たってから狙われた被害者もいると述べたと報じられています。

**現状と対応**
推奨される対応は、会議には公式アプリと招待コードで参加すること、予期しない招待は別の経路で本人確認すること、不要なときはカメラを切ること、不具合の「修正」として渡されたスクリプトを実行しないことです。同記事は、npm や Rust のパッケージの開発者を狙った試みも FBI が確認したと伝えています。

**やさしい解説**
知人そっくりの映像が流れる「壊れたビデオ通話」を見せ、「直すにはこれを入れて」と促す手口です。知人からの誘いでも、会議の途中で何かを入れるよう求められたら、手を止めて、電話など別の手段で本人に確認してください。暗号資産を持つ方や開発者は、特に注意してください。

## 3. ドイツの無人機メーカー Quantum Systems、更新サーバー経由の攻撃で運用に支障

**何が起きたか**
Quantum Systems は、10月下旬に、敵対的な攻撃者による攻撃の一環となるインシデントを検知したと認めました。Der Spiegel と Financial Times は、同社の更新配布サーバーが侵害され、地上管制・任務計画ソフト「QBase」向けの不正な更新ファイルが配られたと報じています（社内関係者の話として）。

**影響範囲**
何社の顧客が更新を入れたかは不明です。報道では、ドイツ軍が予防的に同社の無人機を地上待機とし、演習から外したとされますが、これは同社の声明ではなく報道に基づく情報です。MAD、BfV、BSI が関与していると報じられています。

**現状と対応**
同社は、当局と協力して問題を解決し、無人機が安全に運用を再開できるようにしたと述べています。同社は攻撃者を特定しておらず、ウクライナ支援を理由に狙われたとの見方を示しています。

**やさしい解説**
スマートフォンのアプリ更新に偽物が紛れ込むのと同じ仕組みが、軍用の機器で起きたという話です。一般の利用者が取る操作はありません。ソフトの更新を配る仕組み自体が狙われる点は、企業の IT 担当者にとっても参考になります。

## 4. 国内で委託先・Web サイト経由の情報流出が続く

ScanNetSecurity が11月13日に報じた案件です。各社の発表はそれより前で、日付を併記します。

**何が起きたか・影響範囲**
- **無印良品（良品計画）のオーダーカーテン委託先**：11月2日発表。委託の連鎖の末端（ナノテック）のサーバーが10月19日に不正アクセスを受け、19,933件の顧客情報（氏名、住所、電話番号、注文情報、配送先。対象は2018年4月〜2022年1月の注文）が流出した可能性があります。対象者には郵送で連絡の予定です。
- **ApplyNow（Interview Cloud など）**：11月4日付の最終報。8月9日、分析ツールの公表済みの脆弱性を突かれて侵入されました。応募者・契約者・企業ユーザー計396,920人分と、ApplyNow Sign で契約した30,067人分が対象です。後者にはマイナンバーや口座情報などが含まれ得ます。利用終了企業のデータが削除されていなかった点が、原因の一つとして挙げられています。
- **東急不動産の管理サイト**：10月30日発表。GREEN CROSS PARK の会員情報4,079件と、GREENUP の問い合わせ3件。CMS の脆弱性とアクセス権限の不備が原因とされ、流出の有無は特定できていません。
- **島根県物産協会の「しまねのふるさと直送便」**：11月2日発表。EC-CUBE の Amazon Pay プラグインの脆弱性が悪用され、8月13〜15日に決済した7人のカード情報が漏れた可能性があります。不正利用は確認されていないとされます。

**現状と対応**
各社とも、対象者への個別連絡と再発防止策を進めているとしています。

**やさしい解説**
自分が直接使っていない委託先や、すでに使っていないサービスに預けた情報が流出する例です。届いた通知の内容を確認し、カードの利用明細に身に覚えのないものがないか見てください。パスワードを他のサービスと使い回している場合は変更をお勧めします。

## 今日やること

**一般利用者向け**
- 知人からのビデオ会議の誘いでも、会議中に「修正ツール」を入れるよう求められたら実行せず、別の手段で本人に確認する。
- 通知が届いた場合は内容を確認し、カードの利用明細を見直す。パスワードの使い回しをやめる。

**IT 担当者向け**
- Cursor を使う開発者がいる場合、拡張機能 Anthropic.claude-code の 2.1.312 / 2.1.313 を入れていないか確認し、該当者は Cursor の案内に沿って対処する。
- 取引先に渡している鍵・トークンの棚卸しと、保管期間を過ぎたデータの削除ルールを確認する。
- 公表済みの脆弱性を突かれる事例が多いため、分析ツール・CMS・EC のプラグインの更新状況を点検する。
