## 1. 松屋フーズ：アプリ管理システム侵害で約237万件の利用者情報が流出

**何が起きたか**
松屋フーズは、アプリの管理システムが外部から侵害され、情報が流出したと発表しました。同社は2026年10月28日に把握し、関連サービスを停止しています（Security NEXT の報道による）。

**影響範囲**
- 「松弁ネット」「モバイルオーダー」「松弁デリバリー」の利用者情報：約237万7,000件（会員ID、お届け先住所、氏名、電話番号、松屋ポイント）。
- アプリ会員情報：2,000件の流出を確認し、最大3,000件の可能性（会員ID、都道府県、氏名、電話番号、生年月日、メールアドレス、暗号化されたパスワード、松屋ポイント）。

**現状と対応**
経緯・原因・影響範囲を調査中で、個人情報保護委員会へ報告済み。対象者には順次連絡し、システムの復旧作業を進めているとのことです。

**やさしい解説**
お店の「会員名簿を管理する裏方の事務所」に外から入り込まれ、名簿が持ち出された状態です。名簿には住所や電話番号が含まれるため、「松屋です」と名乗る偽のSMSやメールが届きやすくなります。利用者は、届いた連絡のリンクを開かず公式アプリ・サイトから確認し、松屋と同じパスワードを他サービスで使っている場合は変更してください。

## 2. WordPress 本体の重大な脆弱性：修正公開直後から大量の攻撃

**何が起きたか**
WordPress 本体にリモートでコードを実行される恐れのある脆弱性（CVSS 8.1、CVE 番号なし、アドバイザリ GHSA-4w3m-c66w-69mg）が見つかり、2026年10月28日に修正版が公開されました。公開直後から悪用の試みが続いています。

**影響範囲**
WordPress 4.7 から 7.1.3 まで。Wordfence は直近24時間で約62,969件の攻撃をブロックしたと報告しています。

**現状と対応**
WordPress 7.1.4 へ更新してください。あわせて、`wp-content/upgrade` 配下の PHP ファイルへの不審なアクセス、見覚えのない管理者アカウント・プラグイン・PHP ファイルがないか確認することが推奨されています。

**やさしい解説**
ブログやお店のサイトを作る「土台のソフト」に、外から勝手に命令を実行できる穴が見つかった状態です。穴をふさぐ更新が出た直後に、攻撃者が一斉に試し始めています。自分でサイトを運営している方は、管理画面から早めに更新してください。自動更新が有効なら、すでに適用済みかもしれません（管理画面のバージョン表示で確認を）。

**ソース**
- [WordPress RCE Flaw Draws Nearly 63,000 Attack Attempts in Just 24 Hours（The Hacker News）](https://thehackernews.com/2026/10/wordpress-rce-flaw-draws-nearly-63000.html)

## 3. Ivanti Connect Secure：複数の脆弱性を連鎖させた攻撃、2件が KEV に追加

**何が起きたか**
CISA は2026年10月30日、Ivanti Connect Secure の脆弱性2件（CVE-2026-111357、CVE-2026-118527）を悪用確認済みとして KEV に追加しました。Volexity は、認証回避（CVE-2026-104935）、コード実行、権限昇格を組み合わせ、認証なしで管理者権限に到達する攻撃を10月に報告しており、新たな攻撃者 UTA0576 によるものとされています。

**影響範囲**
CVE-2026-111357 と CVE-2026-118527 は 25.1.1.2 以前、および 22.8R2.5 以前。

**現状と対応**
修正版は 25.1.1.3 と 22.8R2.6。CVE-2026-104935 の修正版は報道に明記がなく、適用状況の確認が必要です。報道によれば、攻撃者はマルウェアの設置より、認証情報や AD の情報、管理者パスワード、BitLocker 回復キーの探索を重視していました。米連邦機関の期限は CVE-2026-111357 が11月2日、CVE-2026-118527 が11月13日です。

**やさしい解説**
社外から社内に入る「VPN の入口」に、小さな穴が3つあり、つなぎ合わせると鍵なしで中に入れてしまう状態です。VPN 機器を使っている会社の IT 担当者は、更新の適用と、不審なログイン履歴の確認を急いでください。一般の利用者が直接できる対応は特にありません。

**ソース**

## 4. Northflank で侵害：保管中の秘密情報が盗まれた前提で対応を

**何が起きたか**
クラウドホスティングの Northflank は2026年10月30日、Wiz からの警告を受けてインシデントを公表しました。「環境変数は復号された」と想定するよう顧客に求めており、複数の顧客から AI の API キーが不正利用されたとの報告が出ています。

**影響範囲**
侵入経路、影響を受けた顧客数、他の認証情報の悪用の有無は未公表です（未確認）。

**現状と対応**
同社は対策パッチを適用し、各種データベースの認証情報ローテーションと全顧客向け監査ログを有効化しました。顧客は、保管していた認証情報と秘密情報をすべて更新し、アドオンの公開アクセスを無効化し、AI プロバイダの利用・請求ログを確認することが推奨されています。

**やさしい解説**
合鍵（パスワードや API キー）を預けていた管理会社が破られた状態です。盗まれた AI の鍵は、他人があなたの費用で AI を使うために悪用されることがあります。Northflank を使っている方は、鍵をすべて作り直し、請求が急に増えていないか確認してください。

**ソース**
- [Northflank security breach leads to abuse of customers' AI API keys（BleepingComputer）](https://www.bleepingcomputer.com/news/security/northflank-security-breach-leads-to-abuse-of-customers-ai-api-keys/)

## 5. Chainalysis：AI を使った攻撃で顧客情報の一部が流出

**何が起きたか**
ブロックチェーン分析の Chainalysis は、外部の攻撃者が「エージェント型の攻撃手法」で内部システムに侵入し、顧客情報の一部にアクセスしたと公表しました（10月中の出来事、公表は10月30日）。

**影響範囲**
ユーザーID、氏名、メールアドレス、組織内の役割区分。調査内容、認証情報、セッショントークンにアクセスされた証拠はないと同社は説明しています。組織ごとの詳細な内訳は後日の予定です。Binance の流出とは無関係としています。

**現状と対応**
脆弱性の修正と防御強化を進めています。顧客には二要素認証の有効化、予期しないパスワード再設定への警戒、Chainalysis を装った詐欺（資金回収をうたうものなど）への注意が呼びかけられています。

**やさしい解説**
名前とメールアドレスが漏れると、本物そっくりのだましメールが作りやすくなります。心当たりのある方は、届いたメールのリンクを開かず、二要素認証を設定しておくと安心です。

## 今日やること

**一般利用者向け**
- 松屋のアプリ・サービスの利用者は、同社を装う SMS・メールのリンクを開かない。同じパスワードを使い回していれば変更する。
- 自分のブログ・サイトで WordPress を使っている場合は、7.1.4 へ更新する。

**IT 担当者向け**
- WordPress を 7.1.4 へ更新し、`wp-content/upgrade` 配下への不審なアクセスや不明な管理者アカウントを確認する。
- Ivanti Connect Secure を 25.1.1.3 / 22.8R2.6 以降へ更新し、CVE-2026-104935 の修正適用も確認する。
- Northflank 利用者は、保管中の全秘密情報を更新し、AI プロバイダの利用・請求を確認する。
