## 1. NTTドコモ：My docomo・ドコモオンラインショップで顧客情報が最大約30万件流出

**何が起きたか**
ドコモは11月4日に外部からの不正アクセスを確認し、11月5日未明から My docomo とドコモオンラインショップの各種手続きを停止しました。調査の結果、緊急メンテナンス前の不正アクセスで一部の顧客情報が流出したと発表しています。

**影響範囲**
- 最大約30万件。氏名・住所・生年月日・携帯電話番号・連絡先電話番号など。
- 原因・侵入経路は調査中（報道時点）。

**現状と対応**
緊急メンテナンスは継続中で、再開時期は未定。新たな流出は確認されていないとされています。該当者には個別に連絡するとのことです。ドコモを装ったメール・SMS・電話への警戒が呼びかけられています。
※発表は11月5日で、直近48時間よりやや前ですが、台帳に未掲載のため本日取り上げました。

**やさしい解説**
お店の会員名簿が外から覗かれたような状態です。パスワードの流出は報じられていませんが、名前・住所・電話番号がそろうと、本物らしい詐欺連絡に使われやすくなります。「ドコモです」というメールや SMS のリンクは開かず、公式アプリや公式サイトから確認してください。

## 2. Claude Code の「今後は確認しない」設定が秘密情報を保存、公開 GitHub で1,122件露出

**何が起きたか**
セキュリティ企業 Apiiro の調査として、Claude Code で「Yes, and don't ask again」を選ぶと、承認したコマンド（中に書かれたパスワードや API キーも含む）がプロジェクトの `.claude/settings.local.json` に保存され、これが公開リポジトリにそのまま載っているケースが多数あると報じられました。

**影響範囲**
- 公開 GitHub 上で、秘密情報を1つ以上含む同ファイルのコピーが1,122件。
- 鍵がまだ有効かは調査側では検証していません。通知を受けた企業1社は「有効だった」と確認したと報じられています。
- ファイルを消しても、過去の履歴やフォークに残るため、露出は解消しません。

**現状と対応**
研究者は、ファイルを削除する前に、そこに一度でも入った認証情報をすべて再発行（ローテーション）するよう勧めています。

**やさしい解説**
「この操作は毎回聞かないで」というメモに、合鍵の型まで書き込んでしまい、そのメモを一緒に公開してしまうイメージです。利用者は、①コマンドに直接パスワードやキーを書かない（環境変数などを使う）、②この設定ファイルを Git に入れない（`.gitignore` に追加）、③心当たりがあれば鍵を再発行、の3点を確認してください。

## 3. 【続報】WordPress：修正版への更新作業中に攻撃される脆弱性（CVE-2026-119977）

**新しい事実**
既報の WordPress 本体 RCE（7.1.4 で修正）に関連し、コア更新の仕組み自体に別の脆弱性（CVE-2026-119977）が見つかったと報じられました。更新時に新バージョンのインストーラが `wp-content/upgrade` 配下の一時フォルダに展開され、Web から到達できる環境では、フォルダ名を推測できる未認証の攻撃者が、削除される前にそれを実行してサーバ上でコードを動かせる可能性があります。

**影響範囲**
WordPress 4.7 〜 7.1.3。Picus Security の研究者が報告。

**現状と対応**
研究者は、更新前に `wp-content/upgrade` への Web アクセスを遮断するよう勧めています。なお、元記事の CISA に関する部分は取得できず確認できていません。

**やさしい解説**
引っ越し作業中、荷物（インストーラ）が一時的に玄関先に置かれ、その間だけ誰でも持ち出せる状態になるようなものです。サイト管理者は、更新を先延ばしにせず、更新の直前に該当フォルダへの外部アクセスをサーバ設定で止めてから実行してください。

**ソース**
- [The Hacker News：Installing the Fix for an Exploited WordPress Flaw Can Expose Some Sites One Last Time](https://thehackernews.com/2026/11/installing-fix-for-exploited-wordpress.html)

## 今日やること

**一般利用者向け**
- ドコモ利用者は、ドコモを名乗る連絡のリンクを開かず、公式サイト・アプリで確認する。

- 既出の SonicWall（CVE-2026-19868）の更新状況（CISA 期限 11月20日）を再確認する。
