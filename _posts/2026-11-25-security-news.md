## 1. 【続報】VMware vCenter に別の重大な認証回避（CVE-2026-123903）

**何が起きたか**
Broadcom が11月24日、vCenter の認証回避（CVE-2026-123903、CVSS 9.8）など複数の欠陥を修正するアドバイザリ（VMSA-2026-0011）を公開しました。以前に悪用が確認された CVE-2026-123890 とは別の問題だと説明されています。

**影響範囲**
- 同じ vmdir（ディレクトリサービス）に関する、ネットワーク経由での認証回避です。
- 同時に、アーカイブ処理に起因する任意ファイル書き込み（CVE-2026-123904、CVSS 7.5、アプライアンス上でのコード実行につながりうる）と、vmdir のサービス拒否3件も修正されました。
- Broadcom は、今回の欠陥の悪用を確認していないとしています。

**現状と対応**
- 修正版：VCF／vSphere Foundation 9.1.x は 9.1.2、9.0.x は 9.0.2.0300、vCenter 8.0 は 8.0 U3m、VCF 5.x は 5.2.5。vCenter 7.0 は延長サポート契約があれば Broadcom に問い合わせ。
- vCenter の管理ネットワークを外部から到達できないように保つことも重要です。

**やさしい解説**
建物の入館ゲート（認証）に、先日見つかった抜け穴とは別の抜け穴が新たに見つかり、修理が出たという話です。まだ悪用の報告はありませんが、前回の事例で狙われた場所なので、早めの更新が安全です。仮想化基盤を管理している担当者向けの話で、一般の利用者が直接行う作業はありません。

- VMSA-2026-0011：<https://github.com/vmware/vcf-security-and-compliance-guidelines/blob/main/security-advisories/vmsa-2026-0011/README.md>

## 2. 韓国電力公社（KEPCO）で約152万人分の情報が流出

**何が起きたか**
KEPCO は、統合顧客サービスのポータル「KEPCO ON」と、取引先管理（SRM）基盤から情報が外部に持ち出されたことを、11月20日に確認したとされます。11月19日にはダークウェブのフォーラムで、データを盗んだとする投稿があったと報じられています（報道は11月24日）。

**影響範囲**
- KEPCO ON が約65万人、SRM が約87万人（職員・取引先従業員を含む）で、合計約152万人です。
- 顧客側では、氏名・住所・電話番号・ID番号に加え、カード番号・口座情報・請求や支払いの詳細が含まれるとされます。
- 侵入経路は公表されていません。AI の使用も確認されていません。フォーラム投稿者と今回の件の関係は、韓国の個人情報保護委員会（PIPC）が確認していません。

**現状と対応**
- KEPCO は対象サービスを停止して外部アクセスを遮断し、対象者への個別通知と当局への報告を行ったとしています。PIPC が調査中です。

**やさしい解説**
公共料金の支払い窓口と取引先の受付窓口の名簿が、まとめて持ち出されたようなものです。カード情報を含むため、悪用されると不正な請求や、なりすましの連絡につながるおそれがあります。KEPCO の利用者は、通知やカード会社からの連絡に注意し、身に覚えのない請求が無いか確認してください。日本の方が直接影響を受ける可能性は低い案件です。

**ソース**
- KEPCO 発表：<https://www.kepco.co.kr/home/media/newsroom/pr/boardView.do?boardMngNo=15&boardNo=3197>
- 韓国個人情報保護委員会（PIPC）：<https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS074&mCode=&nttId=12664>
- SecurityWeek：<https://www.securityweek.com/1-5-million-impacted-by-data-breach-at-south-korean-electric-company-kepco/>

## 3. Check Point のセキュリティ管理サーバを狙う AI 支援型とみられる侵入キャンペーン

**何が起きたか**
セキュリティ企業 GreyNoise が、攻撃者（同社の呼称は GT13）による Check Point のセキュリティ管理サーバへの侵入キャンペーンを報告しました（報道は11月24日）。AI を活用したツールで、スキャンや悪用を自動化していたとされます。

**影響範囲**
- 少なくとも22組織（エネルギー、金融、政府、製造など約12か国）が標的になったとされます。
- 24台の侵害された Check Point サーバからデータが取得されたとされます。
- GreyNoise は、最初にどう侵入したかを特定できていません。攻撃者が持続的なアクセスを保持しており、活動が続いている可能性があるとしています。
- 報道にはパッチやベンダー助言の記載がありません。関連する CVE は攻撃者が使用・試行した多数の既知の欠陥の一覧で、初期侵入の経路とは限りません。

**現状と対応**
- GreyNoise の調査資料に侵害の兆候（IoC）が掲載されているはずですが、本稿では内容を確認していません。該当製品の管理者は、一次ソースで自組織への該当を確認してください。

**やさしい解説**
防犯システムの「管理室」自体に侵入された形です。管理室を押さえられると、各拠点の設定を一括で変えられてしまいます。一般の利用者がすることはありません。Check Point 製品を運用している組織は、管理サーバを外部から直接見える状態にしていないか、ログに不審な管理操作が無いかを点検してください。

**ソース**
- GreyNoise：<https://www.greynoise.io/blog/check-point-security-management-servers-intrusion-campaign>
- SecurityWeek：<https://www.securityweek.com/check-point-security-management-servers-hacked-in-ai-assisted-campaign/>

## 4. WHMCS に複数の脆弱性、ログイン不要の SQL インジェクションも（CVE-2026-82981 ほか）

**何が起きたか**
ホスティング事業者向け顧客管理ソフト WHMCS が11月23日、3件の脆弱性の修正を公表しました。

**影響範囲**
- CVE-2026-82981（CVSS 8.7）：ショッピングカートのログイン不要の SQL インジェクション。顧客情報や管理者のパスワードハッシュが露出しうる。修正版は 9.0.10、8.13.8、9.1.2（アドバイザリ記載）。
- CVE-2026-82979（CVSS 7.1）：クライアント領域の SQL インジェクション（要ログイン）。
- CVE-2026-93700（CVSS 9.0）：メールキャンペーン処理の欠陥（要ログイン）。パッチ適用に加え、予定・進行中のキャンペーンの削除とテンプレートキャッシュの消去が必要。
- 8.0〜8.12 系は修正が提供されないため、修正版へ移行が必要です。悪用の報告はありません。

**現状と対応**
- WHMCS Cloud は自動更新されます。自社で運用している場合は、管理者が更新する必要があります。報道時点で 9.1.2 のビルドが公式のリリースノートに未掲載だった点に注意してください。

**やさしい解説**
ホスティング会社の「顧客受付・請求システム」に、ログイン不要で顧客名簿を覗かれうる穴が見つかった、という話です。自社で WHMCS を運用している方は、早めに更新してください。契約者側（利用者）がすることは特にありません。

- WHMCS（CVE-2026-82979）：<https://help.whmcs.com/m/125386/l/2151340-cve-2026-82979-whmcs-security-update-2026-11-23>
- WHMCS（CVE-2026-93700）：<https://help.whmcs.com/m/125386/l/2151351-cve-2026-93700-whmcs-security-update-2026-11-23>

## 5. 欧州委員会の学習サイト「EU Academy」で利用者情報が流出

**何が起きたか**
欧州委員会は、10月22日に検知した、AI が関与したとされるサイバー攻撃について、11月23日にデータ流出を確認しました。

**影響範囲**
- 流出したのは、EU Academy（委員会外の人も使うオンライン学習サイト）の利用者の氏名とメールアドレスです。人数は未公表で、調査中です。
- 委員会は、職員のデータは影響を受けていないとしています。攻撃者の特定はしていません。中国系グループを疑う報道（Euronews）もありますが、委員会は帰属を示していません。

**現状と対応**
- EU Academy へのアクセスは停止されました。欧州データ保護監督官に通知済みで、個別の連絡はなく、サイト上の告知のみとされています。

**やさしい解説**
オンライン講座の受講者名簿（名前とメールアドレス）が盗まれた状態です。直接の金銭被害につながる情報ではありませんが、本物らしい偽メールが届きやすくなります。EU Academy の利用者は、関連をうたう不審なメールやリンクに注意してください。

**ソース**
- SecurityWeek：<https://www.securityweek.com/european-commission-uncovers-data-breach-in-cyberattack-investigation/>
- Euronews（中国関与の疑い）：<https://www.euronews.com/2026/11/23/exclusive-china-backed-hackers-suspected-behind-ongoing-eu-commission-cyberattack>

## 今日やること

**一般利用者向け**
- KEPCO や EU Academy を利用している場合は、不審なメール・SMS・請求に注意する。
- 流出が相次いでいるため、使い回しているパスワードがあれば変更し、可能なサービスで二段階認証を有効にする。

**IT担当者向け**
- vCenter を運用している場合は、VMSA-2026-0011 に従って修正版へ更新し、管理ネットワークへの外部到達性を確認する。
- Check Point のセキュリティ管理サーバを運用している場合は、GreyNoise の資料で該当の有無とログを確認する。
- WHMCS を自社運用している場合は、修正版へ更新する（CVE-2026-93700 は追加作業も必要）。

## 留意点

- Check Point の件は、初期侵入の経路が未特定で、パッチやベンダー助言の有無も確認できていません。KEPCO の件は、侵入経路・フォーラム投稿者との関係が未確認です。
- 期間外として見送った案件（国内）：京成電鉄のスカイライナー座席予約システム（最大約337万件、11月13日公表）、シェアフル（最大約750万件、11月公表）、九州電力送配電（11月5日公表・13日続報）、トラベルコ（約38万件、11月9日公表）、ヤマダデンキのリフォーム管理システム（最大350万件、11月13日公表）。国内メディアの掲載が11月24〜25日だったもので、公表自体は直近48時間より前です。
- 台帳掲載済みで新しい事実を確認できなかった、または他の案件を優先したため見送った案件：ニトリHD、N-able Mail Assure、ScreenConnect など。
- その他、報道はあったが今回は詳細未確認で見送った案件：Okta が関連づけた新たなリークサイト「INCEPTION」、CIA の非機密システム侵害（匿名関係者の報道）。
- 今回アクセスできなかったサイト：BleepingComputer（HTTP 403）、CISA の alerts ページ（HTTP 404）。
